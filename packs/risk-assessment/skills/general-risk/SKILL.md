# Общая оценка риска — general-risk

Перенесено из AutoClaw legal skills (`general-legal-risk-assessment`, Apache 2.0).
Убран US-корпоративный сленг (board, outside counsel как единственный канал).
Добавлены крупные сделки/заинтересованность, давность, исполнительное производство.

## Назначение

Несколько рисков, которые могут изменить решение. Правовая экспозиция, факт,
бизнес-предпочтение — раздельно.

**Не для:** одной фичи продукта (`feature-risk`); регуляторного экрана по всей
деятельности (`legal-risk`).

## Входные данные

Обязательно: действие/решение.
Опционально: договор, спор, дата, чья сторона, лимиты полномочий.

## Workflow

### Шаг 1 — Граница решения
Что предлагаем, альтернативы, юрисдикция, дата, стороны, кто решает, что вне скоупа.

### Шаг 2 — Факты
Проверено / со слов / допущение / неизвестно / текущие контроли. Какие допущения
переворачивают вывод.

### Шаг 3 — Реестр
Для каждого риска: триггер, факт, норма (проверенная), вероятность, влияние,
контроли (и доказательства, что работают), остаток, эскалация.

Корпоративные РФ-вопросы: крупная сделка (ГК 46), заинтересованность (ГК 45.2),
одобрение органа, полномочия подписанта, давность, обеспечительные меры.

### Шаг 4 — Варианты
Минимум два исполняемых, если решение запрошено. Как меняют экспозицию, без
вымышленной стоимости.

### Шаг 5 — Рекомендация
Что следует из фактов, условия, остаточный риск, кто принимает, что пересмотрит.

## Тестовая фабула

**Решение:** «подписать ДС с новым лимитом ответственности без индексации».

**Ожидание:** варианты (подписать / торговаться / частичное), риски (неустойка
без потолка, инфляция), корпоративные (крупная ли), давность по старым партиям.
Не «подписывай» / «не подписывай» без условий.

## Degraded mode

Без MCP норма `[unverified]`. Не выдумывать риск-аппетит компании.

## Что НЕ делает

- Не перечисляет удалённые гипотезы.
- Не приравнивает законность к рекомендации «делать».
- Не принимает финальный риск.
