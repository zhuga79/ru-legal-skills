# Экспресс-триаж — quick-triage

Перенесено из AutoClaw legal skills (`is-this-a-problem`, Apache 2.0) и переведено
на российские сценарии. Не финальное заключение.

## Назначение

Самый короткий ответ, который не врёт. Если вопрос сложный — маршрут на профильный
skill, а не «развернуть триаж в меморандум».

**Не для:** заключения (`analysis-memo`), реестра рисков (`legal-risk`, `general-risk`).

## Входные данные

Обязательно: вопрос.
Опционально: дата, сторона, сумма.

## Ловушки (RU)

| Звучит как | Спросить |
|---|---|
| Отдать данные вендору | Что за ПДн, кто оператор, что разрешено договором и 152-ФЗ |
| Изменить оферту/правила | Сохранены ли согласия, реклама, ЗоЗПП |
| Использовать чужой знак/контент | Какое письменное разрешение, на какой канал |
| Обучить ИИ на данных клиентов | На чьих данных, было ли согласие на такое использование |
| Автоматическое решение (скоринг, блокировка) | Кто затронут, есть ли человек, 152-ФЗ ст. 16? |
| «Только для внутренних» | Чьи данные — сотрудники, клиенты, третьи лица |
| «Мы уже так делаем» | Что в этот раз иначе |
| Уволить / не принять на работу | Какое основание ТК 77–84, защищённая ли категория |
| Оплатить / получить за границей | Валютный контроль, санкции, 115-ФЗ |
| Выложить переписку / подать в суд | ПДн, КТ, адвокатская тайна |

Если одного вопроса мало — статус `⚠️`, перечислить минимальный набор фактов,
не устраивать допрос.

## Workflow

### Шаг 1 — Переформулировать решение
Что хотят сделать, где, с кем, с какими данными.

### Шаг 2 — Один ловушечный вопрос
Тот, что чаще всего меняет ответ.

### Шаг 3 — Минимальная проверка
Если одна норма решает вопрос и `pravo-mcp` доступен — проверить. Нет — не
заменять памятью. Давность/претензия/срок — всегда флаг.

### Шаг 4 — Статус

**✅ Готовимся** — факты достаточны, вписывается в известное, спец. триггеров нет,
норма проверена. Не «можно подписывать/запускать».

**⚠️ На review** — не хватает решающего факта, нормы, позиции компании или
нужен профильный skill. Назвать что именно.

**🛑 Стоп** — действие трудно обратить, есть разумный материальный риск, конфликт
с прямым запретом, нет критичного материала. Указать, что снимет стоп.

## Тестовая фабула

**Вопрос:** «Можно выложить переписку с клиентом в суд как есть?»

**Ожидание:** 🛑/⚠️ — ПДн, возможно тайна; маскировать третьих лиц, брать
необходимое. Не «да, суд всё равно примет».

## Degraded mode

Без MCP — не цитировать закон как проверенный. Статус всё равно ставится.

## Output

```markdown
[✅ | ⚠️ | 🛑]

**Почему:** [одно предложение: факты vs неизвестное]
**Дальше:** [одно действие]
**Граница:** [допущение, юрисдикция, непроверенное]
```

## Что НЕ делает

- Не превращает «не нашли проблему» в «риска нет».
- Не придумывает политику компании, согласования, сроки.
- Не растёт в меморандум.

## Правовая основа

- 152-ФЗ; ТК РФ ст. 77–84; ГК РФ ст. 195–208 — примеры зон триажа.
