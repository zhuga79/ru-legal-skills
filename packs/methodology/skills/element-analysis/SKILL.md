# Анализ по элементам состава — element-analysis

Полная переработка AutoClaw skill `element-analysis` (Apache 2.0). Вместо
абстрактного «claim/defense/test» — составы требований и возражений по ГК, ТК,
НК, КоАП и процессуальным кодексам. Вместо IRAC — таблица элементов.

## Назначение

Честная карта: какой элемент чем подтверждён. Главный выход — **список пробелов**,
а не вердикт.

**Не для:** выбора способа защиты (`issue-identification`), драфта иска
(`process-documents/isk-sostavlenie`), доказательственной матрицы в формате
дела (`litigation/claim-chart`).

## Входные данные

Обязательно: фабула или материалы + тип требования/возражения (или просьба определить).
Опционально: договор, переписка, расчёты, решения органов.

## Типовые составы (стартовый список)

Не ограничивайся списком — если состав нестандартный, собери его из нормы
через `pravo.search_npa`, не из памяти.

| Тип | Элементы (ориентир) |
|---|---|
| Взыскание долга | обязательство; срок наступил; не исполнено; размер |
| Неустойка | обязательство; нарушение; начисление по договору/закону; период; размер (и ст. 333 ГК как защита) |
| Убытки (ГК 15, 393) | противоправность; причинная связь; размер; вина (если не предприниматель — ГК 401) |
| НЕО (ГК 1102) | приобретение/сбережение; без основания; за счёт потерпевшего; размер |
| Расторжение (ГК 450) | договор; основание (существенное нарушение / ст. 451 / соглашение); претензионный порядок |
| Недействительность | конкретное основание ст. 166–179; кем заявлено; давность (ст. 181) |
| Защита деловой репутации (ГК 152) | распространение; несоответствие действительности; порочащий характер |
| Взыскание зарплаты (ТК) | трудовые отношения; задолженность; расчёт; сроки (ст. 392 ТК) |
| Восстановление на работе | незаконность основания/процедуры (ТК 77–84); категория работника; срок обращения |
| Налоговое доначисление | событие/объект; база; ставка/период; полномочия; процедура (актирование, АО) |

**Возражения:** истечение давности (ГК 199, 196); о зачёте (ГК 410); о несущественности
нарушения; о вине кредитора (ГК 404); о недопустимости доказательств; о пропуске
претензионного порядка.

## Workflow

### Шаг 1 — Норма-источник состава

Через `pravo.search_npa` возьми статью, из которой собираешь элементы. Если
элементов в законе нет «по пунктам» — собери из текста и Пленума, укажи источник
каждого элемента. Не добавляй «по практике обычно ещё требуют X» без ссылки.

### Шаг 2 — Таблица

| № | Элемент | Норма | Факты за | Факты против | Статус |
|---|---|---|---|---|---|
| 1 | Обязательство существует | ГК 309 + договор | договор №, акт | ответчик: не подписывал | indeterminate |

Статусы: `доказано` / `не доказано` / `открыто (нет данных)` / `не применимо`.
Не сливай элементы ради красоты.

### Шаг 3 — Gap-list первым блоком вывода

«Чтобы требование состоялось, ещё нужно: …». Открытый элемент = нет вывода
«обосновано» и нет вывода «отклонено».

### Шаг 4 — Контрсостав

Пройди возражения ответчика по тем же правилам. Давность — всегда отдельно.

### Шаг 5 — Что закрыло бы пробелы

Конкретика: акт, выписка банка, экспертиза, свидетель, ходатайство об истребовании
(`litigation/istrebovanie-dokazatelstv`).

## Тестовая фабула (обязательный прогон навыка)

**Ситуация:** покупатель оплатил по реквизитам из старой переписки, деньги ушли
не тому ООО; продавец требует долг.

**Ожидание от skill:**
- не пишет «переплата = НЕО» автоматически;
- разводит договорный порядок расчётов (ГК 309, 516 для поставки) и ГК 1102;
- помечает: не доказано отсутствие встречного предоставления от продавца;
- предлагает: платёжки, переписка о реквизитах, претензия, давность.

Используй эту фабулу как smoke-test после правок skill.

## Degraded mode

**Если `pravo-mcp` недоступен:** состав можно строить по кодексу, если пользователь
дал текст статьи; иначе `[норма не сверена]`. Не выдумывай элементы.

**Если `kad-mcp` недоступен:** без практики. Не пиши «суды взыскивают» по памяти.

## Output

```markdown
# Анализ состава

## Gap-list (главное)
1. [элемент — что нужно]

## Таблица элементов
[таблица]

## Возражения
[отдельная таблица]

## Что закроет пробелы
[действия]

## Вывод
[только по доказанным элементам; остальное — открыто]
```

## Что НЕ делает

- Не прогнозирует решение суда.
- Не подменяет `claim-chart` (там — привязка к листам дела).
- Не применяется без норм: «кажется, что есть состав» — ошибка.

## Правовая основа

- АПК РФ ст. 65, ГПК РФ ст. 56 — предмет и бремя доказывания.
- ГК РФ ст. 15, 309, 310, 330, 393, 401, 404, 1102 — примеры составов.
- Постановление Пленума ВС РФ от 24.03.2016 № 7 — ответственность по ГК.
