# Суммаризация документа — doc-summary

Перенесено из AutoClaw legal skills (`legal-document-summarization`, Apache 2.0).

## Назначение

Решение-полезная выжимка без сглаживания оговорок.

**Не для:** обзора судебной практики (`case-brief` — по одному акту с выводом/мотивами);
рисков договора (`contract-law/contract-review` — summary ≠ review); пакета документов
(`multi-doc-summary`).

## Входные данные

Обязательно: файл или полный текст.
Опционально: фокус (сроки / деньги / что делать).

## Шаблоны по типу документа

**Решение/определение:** реквизиты, суд, инстанция, стороны, требования, резолютивная
часть (дословно), срок обжалования, куда, мотивы кратко, что исполнять.

**Договор:** стороны, предмет, цена, срок, ответственность, расторжение, применимое
право, подсудность, что необычного.

**Требование органа:** кто, что вменяет, норма, сумма, срок исполнения/обжалования,
куда писать.

**Претензия:** от кого, требования, сумма, срок, основания.

**НПА:** название, статус (действует?), что регулирует, ключевые обязанности, исключения.

## Workflow

1. Тип, название, стороны/орган, юрисдикция, дата, версия, полнота (есть ли приложения).
2. Прочитай полностью, включая определения, сноски, приложения, особые мнения.
3. Извлеки: цель, обязанности, права, условия, исключения, сроки, способы защиты,
   процессуальное положение.
4. Каждая существенная точка — с местом (пункт, статья, лист дела).
5. Отдели: что в документе / что утверждает сторона / что вывод юриста.
6. Флаги: нечитаемые места, отсутствующие приложения, конфликты, устаревшая версия,
   «нужна проверка редакции».

Судебный акт → рекомендуй `litigation/case-brief` для разбора вывода.
Договор → `contract-law/contract-review` для рисков.

## Degraded mode

Работает без MCP. Не заявляй «действующая редакция НПА» без проверки
(`norm-validity-check`). Не «восстанавливай» отсутствующий текст.

## Output

```markdown
# [Название] — выжимка
- Тип / дата / версия:
- Источник и полнота:
- Цель (одно предложение):

## Ключевые положения
1. [пункт] — [место]

## Права, обязанности, сроки
| Кто | Что | Триггер/срок | Исключение | Источник |

## Определения и зависимости
- [...]

## Неясности, конфликты, чего нет
- [...]

## Ограничения
[выжимка ≠ review; статус НПА не подтверждён?]
```

## Что НЕ делает

- Не выбрасывает исключения, меняющие результат.
- Не подразумевает действительность/исполнимость без проверки.
- Не склеивает свой пересказ с цитатой.

## Правовая основа

- АПК РФ ст. 180, ГПК РФ ст. 198 — содержание судебного решения (для шаблона акта).
