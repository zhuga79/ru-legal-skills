# Построение аргументации — argument-chain

Перенесено из AutoClaw legal skills (`argument-chain-construction`, Apache 2.0).
Skill организует рассуждение, не поставляет нормы и факты.

## Назначение

Цепочка, которую можно проверить шаг за шагом: где норма, где факт, где вывод.
Особенно нужна в мотивировке процессуальных документов.

**Не для:** сбора норм (`research-start`), оценки чужого текста (`argument-strength`).

## Входные данные

Обязательно: тезис, который надо обосновать.
Опционально: материалы, аудитория (суд, клиент, орган).

## Метод

### Шаг 1 — Тезис

Зафиксируй точно: юрисдикция, форум, дата, кто говорит.

### Шаг 2 — Юридические посылки

Проверь через `pravo.*`. Вес: ФЗ > письмо; Пленум — толкование.

### Шаг 3 — Фактические посылки

Привяжи к документам. Установлено / спорно / предположение.

### Шаг 4 — Цепочка без пропусков

Даже «очевидное» промежуточное звено пишется.

### Шаг 5 — Проверка цепочки

Подмена понятий (аренда ≠ услуги), пропуск элемента,
отменённая норма, «все суды считают» по одному определению, причинно-следственная
дыра, вывод не следует.

### Шаг 6 — Контраргумент

Сильнейший, с альтернативной цепочкой, если данные допускают.

### Шаг 7 — Вывод

По самой слабой посылке + что изменит вывод.

Аналогия закона (ГК 6) — только при пробеле, с обоснованием. Пленум — толкование
нормы, а не новая норма.

## Тестовая фабула

**Тезис:** «Директор ООО отвечает за убытки от сделки вне полномочий».

**Ожидание:** ГК 53.1 (добросовестность/разумность, вред причинён юрлицу),
ГК 53 (полномочия), устав/доверенность, причинная связь, вина/недобросовестность;
не прыгать в «директор всегда отвечает». Контраргумент: хозяйственное решение
(п. 3 ст. 53.1 — не является противоправным, если иное не установлено).

## Degraded mode

Без `pravo-mcp` посылки помечаются `[норма не сверена]`, вывод — условный.
Без `kad-mcp` не ссылаемся на практику.

## Output

```markdown
# Цель аргументации
[тезис и границы]

## Цепочка
| Шаг | Норма/факт | Подтверждение | Вывод шага | Статус |

## Контраргумент
| Шаг | Посылка | Подтверждение | Последствие |

## Пробелы
- [...]

## Вывод
[ограниченный, с условием]
```

## Что НЕ делает

- Не придумывает посылки.
- Не скрывает неблагоприятную практику.
- Не превращает убедительную аналогию в норму.
