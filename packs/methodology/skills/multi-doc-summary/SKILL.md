# Синтез нескольких документов — multi-doc-summary

Перенесено из AutoClaw legal skills (`multi-document-summarization`, Apache 2.0).

## Назначение

Один согласованный взгляд с сохранением источника каждого утверждения и мест
разногласий.

**Не для:** выжимки одного файла (`doc-summary`), рисков договора (`contract-review`).

## Входные данные

Обязательно: файлы или папка.
Опционально: что нужно — хронология, обязательства, позиция по спору, версия
договора.

## Типовые наборы

- Иск + отзыв + решение + апелляция.
- Договор + ДС + спецификации + протокол разногласий.
- Акт проверки + пояснения + решение ФНС + апелляция.
- Переписка + акты + платёжки (опасно: переписка ≠ соглашение об изменении).

Приоритет источника: судебный акт, вступивший в силу, над перепиской;
изменение договора — только если есть порядок изменения (ГК 450.1, 452).
Поздняя дата ≠ автоматическое «замещает».

## Workflow

### 1. Инвентарь
ID, название, тип, автор, дата, версия, роль, полнота, дубли/утратившие силу.

### 2. Вопрос синтеза
Хронология / обязательства / issues / состояние сделки / иерархия — не пересказ
всего подряд, если нужно решение.

### 3. Извлечение с провенансом
Факты, суммы, сроки, позиции — с ID источника. Слова пользователя, текст
документа и проверенная норма — раздельно.

### 4. Сверка без выдумки
Совпадающее — группируй; конфликты сумм, дат, версий — рядом, не выбирая
«правильное» молча.

### 5. Виды
Хронология, матрица «кто-что-когда», реестр противоречий, версия договора.

## Degraded mode

Работает без MCP. Не «сливай» суммы. Не считай поздний файл более юридически
сильным без основания.

## Output

```markdown
# Синтез пакета

## Инвентарь
| ID | Документ | Дата/версия | Роль | Полнота |

## Главное
[текущая картина для решения]

## Хронология
| Дата | Событие | Источник | Конфликт |

## Обязательства / вопросы
| Тема | Позиция | Источник | Зависимость/дыра |

## Противоречия
| Тема | Источник A | Источник B | Статус |

## Чего нет
- [...]
```

## Что НЕ делает

- Не склеивает цитаты из разных документов.
- Не решает коллизию без основания.
- Не теряет ID при сжатии.

## Правовая основа

- ГК РФ ст. 450.1, 452 — изменение/расторжение договора.
- АПК РФ ст. 69, ГПК РФ ст. 61 — преюдиция (акт суда над актом переписки).
