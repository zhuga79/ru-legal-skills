# Черновик документа — research-drafting

Перенесено из AutoClaw legal skills (`legal-research-drafting`, Apache 2.0) и
адаптировано: юрисдикция РФ — известна, не «гейт-вопрос»; гейт — тип документа,
сторона и полнота фабулы.

## Назначение

Собрать полный, внутренне непротиворечивый черновик. Отделять: проверенный факт /
инструкция клиента / норма / анализ / рекомендация / открытое.

**Не для:** иска (пара `isk-sostavlenie` + `isk-proverka`), окончательного
подписания, решения за клиента.

## Входные данные

Обязательно: тип документа, для кого, цель.
Опционально: фабула, договор, сроки, реквизиты.

## Формальные рамки (частые)

| Документ | Где смотреть |
|---|---|
| Иск | АПК 125–126 / ГПК 131–132; см. `isk-sostavlenie` |
| Отзыв | АПК 131 / ГПК 149; см. `otzyv-na-isk` |
| Апелляция/кассация | АПК 259, 275 / ГПК 322, 378 |
| Претензия | АПК 4 ч. 5 + договор; см. `pretensia-draft` |
| Ходатайство | по предмету (истребование — АПК 66, ГПК 57) |
| Ответ на требование ФНС | срок в требовании; НК 93, 93.1 |
| Договор | существенные условия по типу (ГК) + императив |
| Доверенность | ГК 185; АПК 61–62 спец. полномочия |

**Договор:** перед текстом — существенные условия, императивные нормы, сторона
(чей черновик). Не «нейтральный» шаблон вместо юрисдикции РФ.

## Workflow

1. Тип, отправитель, адресат/суд, срок, желаемый результат, приложения.
2. Прочитай материалы полностью; хронология, issues, пробелы.
3. Нормы через `pravo.*`; непроверенное — не в текст документа как факт.
4. Выбери форму (см. таблицу). Не переноси US-структуры (letterhead «Attorney at Law»).
5. Черновик: реквизиты, содержание, приложения, подпись. Плейсхолдеры `[ЗАПОЛНИТЬ]`
   — явно, не оставляй «...».
6. Проверка: имена, суммы, даты, термины, ссылки, подсудность, полномочия
   подписанта, приложения.

## Degraded mode

Без `pravo-mcp` — структура документа возможна; правовое обоснование —
`[требует проверки]`. Не выдавай черновик за поданный/подписанный.

## Output

Файл/текст черновика + короткая обёртка:

```markdown
# Черновик: [тип]
- Для кого / куда:
- Что нужно от пользователя:
- Что не проверено:
- Что НЕ делает черновик:
```

## Что НЕ делает

- Не подаёт, не подписывает.
- Не выдумывает факты, приложения, полномочия.
- Не заменяет профильные skills для иска/отзыва/претензии.

## Правовая основа

- АПК РФ ст. 125, 126, 62; ГПК РФ ст. 131, 132.
- ГК РФ ст. 452 — порядок изменения договора.
